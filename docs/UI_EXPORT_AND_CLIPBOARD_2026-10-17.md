# TimeEval UI: автоматическое открытие Excel и копирование результатов

## Что изменилось

- На вкладках **Локальный запуск** и **Федеративный запуск** флажок **«Открывать файл после экспорта»** включён по умолчанию. После успешного сохранения `.xlsx` приложение передаёт файл системному обработчику: `os.startfile` (Windows), `open` (macOS), `xdg-open` (Linux). Используется назначенное на компьютере приложение для `.xlsx` — не обязательно Microsoft Excel.
- При отсутствии установленной программы, ошибке ассоциации или запуска появляется предупреждение, но **сохранённый файл не удаляется**. На экране отображается имя сохранённого файла. Флажок позволяет отключить автоматическое открытие.
- Кнопка **«Копировать таблицу»** на обеих вкладках сравнения копирует все строки результатов, включая русские заголовки, как TSV. В Excel достаточно нажать `Ctrl+V`.
- В таблицах результатов `Ctrl+C` копирует выделенные строки (при отсутствии выделения — всю таблицу), `Ctrl+A` выделяет все строки. Вкладка **История** содержит кнопку **«Копировать результаты»** для выбранного архивного эксперимента.
- Копируются **отображаемые значения**, округлённые до четырёх знаков, как в таблице UI. Для полных числовых значений, разбиения клиентов и диагностик необходим XLSX-экспорт.

## Реальная проверка

`xvfb-run -a python -m pytest -q`: 157 passed, 1 skipped на этой версии.

Интеграционный GUI-тест `tests/test_ui_excel_clipboard.py` запускает реальное сравнение K-Means/GMM на Iris, помещает результаты в Tk-таблицу, проверяет содержимое системного буфера обмена, сохраняет настоящий `.xlsx`, проверяет передачу пути системному обработчику, отключение автоматического открытия и ситуацию, когда приложение просмотра недоступно. Дополнительно проверено копирование данных из Истории.

**Ограничение проверки:** физический запуск Microsoft Excel в Windows здесь не выполнялся: ОС-обработчики проверены через моки, а Tk-интерфейс — в виртуальном графическом дисплее Linux. Системная команда может успешно стартовать, но при неверной файловой ассоциации файл всё равно может не открыть конкретное приложение.
