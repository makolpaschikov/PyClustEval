# Benchmark and dataset utilities (tools)

## Summary

Find command-line scripts for fetching datasets, generating benchmark tables and examining campaign measurements.

## References

- [fetch_dry_bean.py](fetch_dry_bean.py) — Fetch the Dry Bean dataset.
- [fetch_mnist.py](fetch_mnist.py) — Fetch MNIST data.
- [compatibility_matrix.py](compatibility_matrix.py) — Generate an algorithm-by-dataset compatibility table.
- [density_sensitivity.py](density_sensitivity.py) — Generate the density sensitivity table.
- [rebuild_validation_from_history.py](rebuild_validation_from_history.py) — Rebuild empirical audit outputs from saved histories or exported campaigns.
- [campaign_profile/observations.py](campaign_profile/observations.py) — Inspect host capacity and measurements from saved campaign attempts.
