# Приоритет P0 (критично для MVP)

## 1. Flower Execution Layer ❌

**Статус:** не реализован.

Необходимо:

-   реализовать `ExecutionBackend`;
-   реализовать `FlowerExecution`;
-   запускать Flower Simulation;
-   создавать `ServerApp`;
-   создавать `ClientApp`;
-   поддерживать пользовательские `Strategy`;
-   возвращать единый `BenchmarkResult`.

------------------------------------------------------------------------

## 2. Единый интерфейс алгоритмов ⚠

Сейчас используются объекты sklearn напрямую.

Необходимо:

-   ввести `ClusteringAlgorithm`;
-   реализовать адаптеры для sklearn;
-   реализовать адаптеры для Flower;
-   реализовать адаптеры для пользовательских алгоритмов.

------------------------------------------------------------------------

## 3. Experiment Manager ⚠

Отсутствует координатор выполнения экспериментов.

Должен:

-   читать конфигурацию;
-   создавать Experiment;
-   запускать Planner;
-   запускать Runner;
-   сохранять результаты.

------------------------------------------------------------------------

# Definition of Done

Архитектура считается реализованной, когда:

-   [ ] любой алгоритм подключается без изменения ядра;
-   [ ] доступны LocalExecution и FlowerExecution;
-   [ ] любой эксперимент воспроизводим по YAML;
-   [ ] все результаты сохраняются в едином формате;
-   [ ] метрики расширяются через плагины;
-   [ ] добавление нового backend не требует изменения Benchmark Core.
